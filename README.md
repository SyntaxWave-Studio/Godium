# 🚀 GodiumIDE

**GodiumIDE** — это мой первый серьёзный проект на C++. Высокопроизводительный, отзывчивый и минималистичный редактор кода, построенный на базе **Qt6 (C++17)**. 

Проект создается как быстрая и нативная альтернатива тяжеловесным Electron-приложениям по типу VS Code. Главная цель — доказать, что современный и удобный инструмент разработки может быть экстремально легким.

---

## 🎯 Философия и архитектура

*   **📦 Монолитное ядро:** Из коробки поставляются только базовые модули — встроенный проводник и производительное окно редактора.
*   **🔌 Модульность (Plugin-first):** Любой дополнительный функционал (подсветка синтаксиса, автодополнение LSP, терминал, Git) вынесен в изолированные плагины, которые загружаются только при необходимости.
*   **📐 Умный сплит интерфейса:** Кастомная система динамических окон позволяет гибко делить экран на независимые рабочие области без утечек памяти и просадок FPS.
*   **⚙️ Глубокая оптимизация:** Проект собирается через CMake с агрессивными флагами сжатия машинного кода, а линкер вырезает весь неиспользуемый код библиотек Qt.
